# applicabilità dei sensori Mocopi per lo sport
Questa repository contiene il materiale in appendice della tesi triennale svolta dallo studente Rayan Alessandro Tekaia. Sono visibili il codice scritto in python, la libreria usata per leggere i file BVH. Vengono anche forniti due esempi di file BVH, per i sistemi Mocopi e Optitrack.
